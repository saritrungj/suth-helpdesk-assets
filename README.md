# Hospital IT Asset Management (SUTH Helpdesk)

Welcome to the internal project repository for SUTH Helpdesk (IT Asset Management).

## Project Structure
- `/frontend` - Vue.js frontend application
- `/backend` - Express.js backend API
- `/database` - Database schema and scripts
- `/docs` - Project documentation and planning

## Getting Started

### Prerequisites
- Node.js
- MySQL

### Running the Backend
```bash
cd backend
# Create your local .env file based on the example
cp .env.example .env
npm install
npm run dev
```

### Running the Frontend
```bash
cd frontend
npm install
npm run dev
```
