# คำที่ใช้บนหน้าจอ

คำเดียวต่อหนึ่งความหมาย ใช้ภาษาที่เจ้าหน้าที่พูดกันจริง ไม่ใช่ศัพท์บัญชีหรือศัพท์ระบบ (#198)
ตัวเลขหน้าเปลี่ยนเป็น "ยอดพิมพ์" / "ยอดพิมพ์หลังหัก 2%" ตามที่ผู้ใช้ขอ (#206) — แทน "หน้าที่พิมพ์" / "หน้าที่คิดเงิน" ของ #198
เพิ่มข้อความใหม่ให้ใช้คำในตารางนี้ ถ้าไม่มีคำที่ต้องการ เพิ่มแถวที่นี่ก่อน

แนวทางอ้างอิง: เขียนให้อ่านง่ายแม้ผู้อ่านเป็นผู้เชี่ยวชาญ ([GOV.UK — writing for user interfaces](https://www.gov.uk/guidance/content-design/writing-for-gov-uk))

| ความหมาย | ใช้ | ไม่ใช้ |
|---|---|---|
| งานบันทึกตัวเลขรายเดือน (ชื่อเมนู ปุ่ม คำสั่ง) | จำนวนพิมพ์ — เช่น "บันทึกจำนวนพิมพ์" | ยอด (คำเดียวลอยๆ) |
| ตัวเลขหน้าตามที่บันทึก ก่อนหัก (ป้าย หัวคอลัมน์ การ์ดตัวเลข) | ยอดพิมพ์ | หน้าที่พิมพ์, ยอดพิมพ์จริง, หน้าดิบ, จำนวนหน้าดิบ |
| หน้าหลังหัก 2% ที่ใช้คิดเงิน | ยอดพิมพ์หลังหัก 2% | หน้าที่คิดเงิน, ยอดพิมพ์สุทธิ, หน้าสุทธิ, สุทธิหลังหัก 2% |
| การหัก 2% ตามสัญญา | หัก 2% | ส่วนลด 2% |
| ตัวเลขบนหน้าปัดของเครื่อง | เลขมิเตอร์ | ยอดมิเตอร์ |
| เงินที่ผู้ให้เช่าเรียกเก็บต่องวด | เงินตามใบแจ้งหนี้ | ยอดตามใบแจ้งหนี้ |
| ค่าใช้จ่ายรวม (คิดจากยอดพิมพ์หลังหัก 2% แล้ว) | ค่าใช้จ่าย | ค่าใช้จ่ายสุทธิ |
| ค่าใช้จ่าย ÷ ยอดพิมพ์หลังหัก 2% | เฉลี่ยหน้าละ | ต้นทุนเฉลี่ยต่อหน้า |
| แถวที่ไฟล์นำเข้าจะเพิ่ม / แทนค่าเดิม | ตัวเลขใหม่ / แทนที่ | ยอดใหม่ / เขียนทับ |
| เครื่องพิมพ์ในระบบ | เครื่อง, เครื่องพิมพ์ | ทรัพย์สิน, อุปกรณ์ |

## หลักการเขียน

- ป้ายและปุ่มสั้นที่สุดที่ยังชัด — คำอธิบายยาวใต้หัวหน้าเป็นข้อยกเว้น ไม่ใช่ค่าเริ่มต้น
- บอกสิ่งที่คนต้องทำหรือสิ่งที่จะเกิด ไม่อธิบายว่าระบบทำงานอย่างไร
- ช่องว่างกับศูนย์ต่างกัน: "ยังไม่ได้บันทึก" ≠ "ไม่มีการพิมพ์"
- ข้อความทุกข้อความต้องมีคำแปลใน `apps/web/src/lib/locales/en.json` และเทส `locale.test.js` กันคำแปลที่ไม่มีที่ใช้
