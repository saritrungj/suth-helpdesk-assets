# Dashboard สำหรับผู้บริหาร

หน้า Dashboard ตอบคำถามหลักสามข้อ: ใช้เงินเท่าไร แนวโน้มเปลี่ยนอย่างไร และเงินอยู่ที่แผนกหรือสัญญาใด จากนั้นผู้ใช้กดเจาะรายการต้นทางได้โดยไม่เสียบริบทของรายงาน

## การนำเสนอ

- ใช้โครงหน้าและธีมกลางเดียวกับทะเบียนและรายงานค่าใช้จ่าย: `UiPageHeader`, `UiCard`, `UiStat` รวมถึงสีพื้น ขอบ มุมโค้ง เงา และขนาดตัวอักษร ไม่ติดธีมเฉพาะ Dashboard ที่เปลือกแอป
- กราฟแท่งเปรียบเทียบค่าใช้จ่ายแต่ละเดือนโดยเริ่มแกนที่ศูนย์; กราฟเส้นสำหรับแนวโน้มยอดพิมพ์ สลับอ่านเป็นตารางได้
- แสดงเฉพาะเดือนที่มีรายการ เดือนที่บันทึกศูนย์ยังอยู่ ส่วนราคาที่ไม่ยืนยันแสดงขีดแทนศูนย์
- แผนกใช้แถบแนวนอนเพื่อเปรียบเทียบชื่อยาว ส่วนสัญญาใช้รายการพร้อมยอดที่กดเปิดรายละเอียดได้
- งานที่ต้องติดตามอยู่ในลิ้นชักแจ้งเตือนของ Sidebar **ที่เดียว** ไม่มีสำเนาบนหน้านี้ (#83); ข้อจำกัดของตัวเลขแต่ละตัว เช่น "ยังยืนยันราคาไม่ได้ N รายการ" ติดอยู่กับตัวเลขนั้นเอง ส่วนความครบถ้วนของข้อมูลเป็นบริบทของรายงานตาม [ADR-0018](../decisions/0018-separate-installation-status.md)

## การเจาะข้อมูลและส่งออก

กดยอดค่าใช้จ่ายเพื่อดูรายละเอียดทั้งหมด หรือเลือกเดือน แผนก หรือสัญญาเพื่อจำกัดขอบเขต แผงรายละเอียดแยกกลุ่มตามแผนก สัญญา เครื่อง หรือเดือนได้ การค้นหาจะกรองทั้งตาราง ยอดสรุป และรายการที่ส่งออก Excel โดยมีช่วงรายงานและสถานะราคากำกับ

ปุ่มส่งออกการ์ดสร้าง PNG ที่มีตัวเลข กราฟ เดือน สัญญา และวันที่สร้าง เหมาะกับแนบรายงานหรือสไลด์ ภาพเป็นข้อมูล ณ เวลาที่กดส่งออก

ยอดเงินรับจาก HTTP API เดิม รวมผ่านหน่วยสตางค์ใน `packages/domain` โดยไม่หาราคาหรือคำนวณส่วนลดใหม่ การจัดกลุ่มใช้ชื่อและรหัสประวัติที่ API ส่งมา ไม่ย้อนใช้สถานที่ปัจจุบัน ขอบเขตความถูกต้องของราคาขึ้นกับ API ตาม [ADR-0019](../decisions/0019-effective-pricing-history.md): เมื่อราคาไม่ครบ แสดงจำนวนรายการที่ไม่ยืนยันคู่กับยอดเงิน และงดข้อสรุปอันดับกับเปอร์เซ็นต์เพิ่ม–ลด

## แนวทางอ้างอิง

- [Ramp — Travel admin dashboard and reporting](https://support.ramp.com/travel-admin-dashboard-and-reporting/): เริ่มจากคำถามด้านค่าใช้จ่าย ให้การ์ดและกราฟเปิดรายละเอียดที่แยกกลุ่มและส่งออกได้
- [Tableau — Actions and Dashboards](https://help.tableau.com/current/pro/desktop/en-us/actions_dashboards.htm): ใช้การเลือกข้อมูลในภาพรวมเป็นทางเข้าสู่ขอบเขตรายละเอียด

อ้างอิงพฤติกรรมการวิเคราะห์จากเอกสารของผู้ผลิต ไม่ใช่นำรูปภาพหรือสินทรัพย์จากผลิตภัณฑ์เหล่านั้นมาใช้ในแอป
