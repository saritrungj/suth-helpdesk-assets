# Dashboard สำหรับผู้บริหาร

หน้า Dashboard ตอบคำถามหลักสามข้อ: ใช้เงินและพิมพ์เท่าไร หน่วยงานหรือสัญญาใดต่างกัน และแนวโน้มเปลี่ยนอย่างไร จากนั้นผู้ใช้กดเจาะรายการต้นทางได้โดยไม่เสียบริบทของรายงาน

## การนำเสนอ

- ใช้โครงหน้าและธีมกลางเดียวกับทะเบียนและรายงานค่าใช้จ่าย: `UiPageHeader`, `UiCard`, `UiStat` รวมถึงสีพื้น ขอบ มุมโค้ง เงา และขนาดตัวอักษร ไม่ติดธีมเฉพาะ Dashboard ที่เปลือกแอป
- ช่วงเวลาเป็นขอบเขตของตัวเลขทั้งหน้า ส่วนพื้นที่เปรียบเทียบใช้ตัวเลือกชุดเดียวตามลำดับ: เปรียบเทียบตามภาพรวม ฝ่าย แผนก สัญญา อาคาร เครื่อง หรือปีงบ → เลือกรายการที่จะเทียบ → ตัวชี้วัด อันดับมาก–น้อยไม่อยู่บนหน้าจอ แต่อยู่ในแผ่น “อันดับ” ของไฟล์ Excel (#115)
- ตัวเลขสำคัญ แผงรายละเอียด กราฟ ตาราง และไฟล์ Excel ใช้ขอบเขตเดียวกัน เลือกรายการมาเทียบเองแล้วการ์ดเป็นยอดของรายการที่เลือก ส่วนภาพรวมและรายการที่ระบบเลือกให้เป็นยอดทุกหน่วยงาน — ระบบเลือกให้เพื่อให้เปิดหน้ามาเห็นกราฟทันที ไม่ได้แปลว่าผู้ใช้จำกัดขอบเขตไว้ บรรทัดเหนือการ์ดบอกขอบเขตนี้เสมอ
- เปอร์เซ็นต์เทียบช่วงก่อนหน้าใช้เดือนที่ API กำหนด (ยาวเท่ากันและอยู่ในปีงบเดียวกัน) แต่คิดยอดจากรายการชุดเดียวกับช่วงที่ดู ถ้าช่วงใดยังยืนยันราคาไม่ครบหรือไม่มียอดของขอบเขตนั้น จะบอกเหตุผลแทนการแสดงเปอร์เซ็นต์
- การ์ดที่สามนับเครื่องที่มียอดในขอบเขต จำนวนเครื่องในทะเบียนวันนี้และความครบถ้วนทั้งองค์กรเป็นข้อมูลอ้างอิงประกอบ ไม่ใช่ตัวหารของขอบเขตที่เลือก
- เลือกฝ่ายหรือแผนกตั้งแต่ 2 รายการ มีปุ่ม “วิเคราะห์ส่วนต่าง” พาไปหน้าเปรียบเทียบพร้อมรายการ เดือน และตัวชี้วัดเดิม กดย้อนกลับเพื่อกลับมาที่มุมมองเดิม
- ภาพรวมและรายการที่เลือกใช้กราฟเส้นสำหรับแนวโน้มรายเดือน การเทียบช่วงฐานใช้กราฟแท่งแนวนอน โดยช่วงฐานกับช่วงที่ดูวางคู่กันต่อหน่วยงาน ทุกมุมมองมีตารางตัวเลขชุดเดียวกับกราฟ
- แสดงเฉพาะเดือนที่มีรายการ เดือนที่บันทึกศูนย์ยังอยู่ ส่วนราคาที่ไม่ยืนยันแสดงขีดแทนศูนย์
- “ยอดพิมพ์” หมายถึงยอดพิมพ์จริงที่บันทึก และแสดงยอดสุทธิหลังหัก 2% ประกอบ ค่าใช้จ่ายยังคำนวณจากยอดสุทธิตามกฎโดเมน
- อันดับมีไว้ชี้จุดที่ควรตรวจสอบ ไม่ใช่ตัดสินความสิ้นเปลือง เพราะยอดรวมขึ้นกับจำนวนเครื่องและลักษณะงานของแต่ละกลุ่ม ไฟล์ส่งออกจึงแสดงจำนวนเครื่องและสถานะข้อมูลประกอบอันดับเสมอ
- ตัวเลือกการเปรียบเทียบอยู่ใน URL จึงเปิดรายละเอียดแล้วกดย้อนกลับได้มุมมองเดิม
- งานที่ต้องติดตามอยู่ในลิ้นชักแจ้งเตือนของ Sidebar **ที่เดียว** ไม่มีสำเนาบนหน้านี้ (#83); ข้อจำกัดของตัวเลขแต่ละตัว เช่น "ยังยืนยันราคาไม่ได้ N รายการ" ติดอยู่กับตัวเลขนั้นเอง ส่วนความครบถ้วนของข้อมูลเป็นบริบทของรายงานตาม [ADR-0018](../decisions/0018-separate-installation-status.md)

## การเจาะข้อมูลและส่งออก

กดการ์ดตัวเลขสำคัญหรือรายการในตารางเปรียบเทียบเพื่อดูข้อมูลรายเครื่องของขอบเขตเดียวกับการ์ด แผงรายละเอียดแยกกลุ่มตามแผนก สัญญา เครื่อง หรือเดือนได้ การค้นหาจะกรองทั้งตาราง ยอดสรุป และรายการที่ส่งออก Excel โดยมีช่วงรายงานและสถานะราคากำกับ

ปุ่มส่งออก Excel ของหน้าภาพรวมและหน้าเปรียบเทียบทุกโหมด (เดือน สัญญา อาคาร ฝ่าย/แผนก) สร้างไฟล์เดียวสามแผ่นรูปแบบเดียวกัน: “เปรียบเทียบ” มีตารางกับกราฟ Excel ที่แก้ต่อได้ “ข้อมูลรายละเอียด” เก็บข้อมูลต้นทางตามขอบเขต และ “เงื่อนไขรายงาน” บอกช่วงเวลา ตัวเลือก ตัวชี้วัด สถานะราคา และเวลาส่งออก เมนูข้างปุ่มมีตัวเลือกส่งเฉพาะข้อมูลดิบสำหรับงานตรวจยอดต่อ ระหว่างสร้างไฟล์ปุ่มกดซ้ำไม่ได้ และถ้าส่งออกไม่สำเร็จจะบอกข้อผิดพลาดพร้อมปุ่มลองใหม่ หน้าเปรียบเทียบเก็บสัญญา/อาคารที่เลือกและตัวกรองไว้ใน URL เดือนที่เลือกแต่ไม่มีข้อมูลยังเป็นช่องว่างในไฟล์

แผ่น “อันดับ” มีทุกรายการของมิติที่ดูอยู่เรียงมาก→น้อยตามตัวชี้วัดบนจอ (#115) เกินสิบรายการได้กราฟสองใบคือ 10 อันดับแรกและ 10 อันดับท้าย ไม่เกินสิบได้ใบเดียวที่มีครบทุกรายการ เพราะการแบ่งมากสุด/น้อยสุดจะได้กราฟสองใบที่ครอบแถวชุดเดียวกันแต่ติดป้ายขัดกันเอง ส่วนแผ่นข้อมูลรายละเอียดเก็บเฉพาะรายการที่ผู้ใช้เลือก และเก็บทุกหน่วยงานในขอบเขตเมื่อระบบเลือกรายการให้ เพื่อให้ไฟล์อธิบายกราฟและตรวจย้อนกลับได้โดยไม่ปนข้อมูลนอกขอบเขต

ยอดเงินรับจาก HTTP API เดิม รวมผ่านหน่วยสตางค์ใน `packages/domain` โดยไม่หาราคาหรือคำนวณส่วนลดใหม่ การจัดกลุ่มใช้ชื่อและรหัสประวัติที่ API ส่งมา ไม่ย้อนใช้สถานที่ปัจจุบัน ขอบเขตความถูกต้องของราคาขึ้นกับ API ตาม [ADR-0019](../decisions/0019-effective-pricing-history.md): เมื่อราคาไม่ครบ แสดงจำนวนรายการที่ไม่ยืนยันคู่กับยอดเงิน และงดข้อสรุปอันดับกับส่วนต่างค่าใช้จ่าย หากค่าฐานเป็นศูนย์จะแสดงส่วนต่างจริงแต่ไม่คำนวณเปอร์เซ็นต์

## แนวทางอ้างอิง

- [Ramp — Travel admin dashboard and reporting](https://support.ramp.com/travel-admin-dashboard-and-reporting/): เริ่มจากคำถามด้านค่าใช้จ่าย ให้การ์ดและกราฟเปิดรายละเอียดที่แยกกลุ่มและส่งออกได้
- [Tableau — Actions and Dashboards](https://help.tableau.com/current/pro/desktop/en-us/actions_dashboards.htm): ใช้การเลือกข้อมูลในภาพรวมเป็นทางเข้าสู่ขอบเขตรายละเอียด

อ้างอิงพฤติกรรมการวิเคราะห์จากเอกสารของผู้ผลิต ไม่ใช่นำรูปภาพหรือสินทรัพย์จากผลิตภัณฑ์เหล่านั้นมาใช้ในแอป
