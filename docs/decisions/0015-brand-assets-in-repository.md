# 0015 — เก็บ brand asset ของเจ้าของระบบไว้ใน repository

**สถานะ:** Accepted

## บริบท

`docs/explanation/design-references.md` เคยมีกฎเดียวครอบทุกอย่างว่า **"ไม่คัดลอกโลโก้ ภาพ
ไอคอน ตัวอักษร หรือไฟล์ใดๆ เข้ามาใน repository นี้ artwork ทุกชิ้นใน SUTH สร้างใหม่ด้วย
CSS/SVG จากสีแบรนด์ของโรงพยาบาลเอง"**

กฎนั้นเขียนขึ้นตอนที่แหล่งอ้างอิงทั้งหมดเป็นงานของคนอื่น — Linear, Stripe, Attio, งานบน
Dribbble — ซึ่งการดึงไฟล์ของเขาเข้ามาคือการละเมิดจริง ตอนนั้นจึงไม่มีเหตุให้แยกแยะว่า
"ไฟล์ของใคร"

งาน [#47](https://github.com/saritrungj/suth-helpdesk-assets/issues/47) ทำให้ข้อแตกต่างนั้น
สำคัญขึ้นมา เจ้าของระบบส่งไฟล์โลโก้ SUTH ฉบับจริงมาให้ใช้กับงานนี้โดยตรง กฎเดิมอ่านตรงตัว
แล้วห้ามไฟล์นั้นด้วย ทั้งที่เป็นทรัพย์สินของผู้ว่าจ้างเอง และข้อกำหนดของงานระบุชัดว่า
**"ไม่วาดใหม่"** — ให้ใช้ภาพต้นฉบับและ exact crop เท่านั้น เพราะโลโก้ที่วาดเลียนแบบด้วย
CSS/SVG ไม่ใช่โลโก้ของโรงพยาบาล มันคือของปลอมที่หน้าตาใกล้เคียง

ทางเลือกที่จะไม่แก้กฎแล้วเก็บไฟล์ไว้นอก repository ถูกปฏิเสธด้วยข้อกำหนดของงานเช่นกัน:
ต้นฉบับต้อง **"ให้ผู้พัฒนาคนถัดไปเข้าถึงได้จากโปรเจกต์"** asset ที่อยู่ใน Drive หรือแชท
หายไปพร้อมคนที่ถือลิงก์เสมอ

## การตัดสินใจ

แยกกฎเดียวออกเป็นสองกฎ ตาม **เจ้าของไฟล์** ไม่ใช่ตามชนิดของไฟล์

- **asset ของแหล่งอ้างอิงภายนอก — ห้ามเข้า repository เด็ดขาด** ใช้ได้เฉพาะการศึกษา
  องค์ประกอบและพฤติกรรม ข้อห้ามนี้ไม่ผ่อนลง
- **brand asset ของเจ้าของระบบ — เก็บได้** โดยมีเงื่อนไขว่าต้องบันทึกที่มาไว้ และมี
  บ้านเดียว

บ้านของมันคือ `docs/assets/brand/` — ต้นฉบับที่ผู้ใช้ส่งมาเก็บไว้โดยไม่แก้ภาพ พร้อม
`README.md` ที่บอกว่าไฟล์ไหนมาจากไหน และ derivative ขนาดเว็บถูกสร้างด้วยพารามิเตอร์ใด
ส่วนไฟล์ที่เบราว์เซอร์โหลดจริงอยู่ที่ `apps/web/public/brand/` และทุกจุดในโค้ดอ้างผ่าน
`BRAND_ASSETS` ใน `apps/web/src/app/brand.js` ที่เดียว ห้ามพิมพ์ path ซ้ำใน component

## ผลที่ตามมา

- ย่อหน้าเรื่องลิขสิทธิ์ใน `design-references.md` ถูกเขียนใหม่ให้ตรงกับสองกฎนี้ และชี้มาที่
  ADR ฉบับนี้กับ `docs/assets/brand/README.md`
- repository โตขึ้นจากไฟล์ต้นฉบับ (`suth-horizontal-source.png` ~1.1 MB) ซึ่งเป็นราคาที่
  ยอมจ่ายเพื่อให้สร้าง asset ชุดใหม่ได้โดยไม่ต้องตามหาไฟล์จากใคร ไฟล์นี้ไม่ถูกส่งถึง
  เบราว์เซอร์ — มีเฉพาะ derivative ใน `public/brand/` เท่านั้นที่ถูกโหลด
- โฟลเดอร์ `brand/` ที่รากเป็นของรุ่นก่อนหน้า ไฟล์ในนั้นไม่ถูกอ้างจากโค้ดแล้ว `README.md`
  ของมันชี้มาที่บ้านใหม่ และเก็บไว้เป็นบันทึกที่มาเท่านั้น
- กฎนี้ไม่เปิดทางให้ asset ของ reference ภายนอกเข้ามาแม้แต่ไฟล์เดียว ถ้าวันหนึ่งอยากใช้
  ของใครสักคนจริงๆ ต้องเขียน ADR ใหม่พร้อมหลักฐานสิทธิ์การใช้งาน
