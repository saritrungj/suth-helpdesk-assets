# 0036 — กราฟแบบแอปหุ้นด้วย Lightweight Charts และหน้าเปรียบเทียบแบบรายการหุ้น

- สถานะ: Accepted
- วันที่: 2026-09-24
- Issue: #212

## บริบท

ผู้ใช้บอกตรงๆ ว่ากราฟ "ดูโคตรยาก" และไม่เอากราฟแท่ง หน้าเปรียบเทียบวาดทุกกลุ่มพร้อมกัน (สูงสุด 8 เส้น) หรือแท่งแนวนอน
เส้นซ้อนกันจนอ่านไม่ออก หน้าภาพรวมไม่บอกว่าเดือนที่ยอดต่ำเป็นเพราะใช้น้อยหรือเพราะยังกรอกไม่ครบ
และ chart.js ต้องมีโค้ดของเราเองทั้งเรื่องเส้นเล็ง ป้ายค่าล่าสุด และการปิดแอนิเมชัน

## การตัดสินใจ

1. ใช้ **TradingView Lightweight Charts** (Apache-2.0) ผ่าน `ui/UiStockChart.vue` ตัวเดียวแทน `UiChart` + chart.js
   - เส้นเดียว = เส้นพร้อมพื้นไล่สี หลายเส้น = เส้นล้วน, เส้นเล็งพร้อมกล่องค่าของทุกเส้น, ป้ายค่าล่าสุดที่แกนขวา
   - แกนนอนคือลำดับเดือน (แปลงเป็นเวลาสมมุติภายใน) เดือนที่ไม่มีข้อมูลเป็นช่องว่าง
   - จุดเตือน "เดือนที่ยังกรอกไม่ครบ" และหมายเหตุในกล่องค่า
   - สลับเป็นตารางได้ทุกกราฟ (เหตุผลเดิมเรื่อง contrast และโปรแกรมอ่านจอ)
   - ไม่ export จาก `ui/index.js` — โหลดเฉพาะหน้าที่วาดกราฟ `scripts/check-bundle-budget.cjs` จับถ้าหลุดเข้าไฟล์ที่ทุกหน้าโหลด
   - คงโลโก้ TradingView ตามเงื่อนไขสัญญาอนุญาต
2. หน้าเปรียบเทียบเป็น **รายการหุ้น (watchlist)**: ตารางมีช่องติ๊กสีเดียวกับเส้น สัดส่วน และเส้นจิ๋ว (`UiSparkline`)
   กราฟวาดเฉพาะที่ติ๊ก ค่าเริ่มต้น 3 อันดับแรก สูงสุด 5 เส้น สีผูกกับรายการ (`stableSlots`) ทั้งกราฟและตาราง
   ช่วงที่มีเดือนเดียวไม่วาดเส้นจุดเดียว แต่บอกให้อ่านสัดส่วนจากตาราง
3. ช่องปีงบและ "เปรียบเทียบตาม ปีงบ" แสดงเมื่อมีข้อมูลอย่างน้อยสองปีงบเท่านั้น
4. หน้าภาพรวมแสดงแกนครบ 12 เดือนของปีงบ เส้นยอดตามใบแจ้งหนี้ (เลือกสัญญาเดียวหรือทุกสัญญา) และแถบความครบถ้วนของข้อมูล

## ทางเลือกที่ตัดทิ้ง

**แต่ง chart.js ให้เหมือนกราฟหุ้น** — ต้องเขียนเส้นเล็ง ป้ายค่าล่าสุด และกล่องค่าหลายเส้นเองทั้งหมด ไฟล์ใหญ่กว่า
และยังต้องดูแลแอนิเมชันเรื่อง prefers-reduced-motion

**ECharts / ApexCharts** — ใหญ่กว่าหลายเท่าสำหรับกราฟเส้นรายเดือน

**วาดทุกกลุ่มแต่ซ่อนผ่านคำอธิบายสี** — ผู้ใช้ต้องกดปิดทีละเส้นเพื่อให้อ่านได้ ค่าเริ่มต้นจึงยังอ่านไม่ออก

## ผลที่ตามมา

- กราฟแท่งหายจากระบบ คำขอ "เทียบสัดส่วน" ตอบด้วยคอลัมน์สัดส่วนในตาราง
- `useChartTheme` เหลือแค่สีจาก token — ไม่มีแอนิเมชันให้ปิดแล้ว
- ข้อความบนกล่องค่าและตารางของกราฟใช้ชื่อเดือนเต็ม (เช่น "ตุลาคม 2568") แกนใช้ชื่อย่อ
