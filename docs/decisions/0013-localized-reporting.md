# 0013 — แยกภาษาแสดงผลออกจากข้อมูลรายงาน

**สถานะ:** Accepted

## บริบท

ผู้ใช้ต้องการไทยและอังกฤษทั้งระบบ รวมทั้งวันที่ รายงาน และข้อความช่วยการเข้าถึง โดยชื่อหน่วยงานและข้อมูลที่บันทึกไว้ต้องไม่เปลี่ยนตามภาษา

## การตัดสินใจ

- ใช้พจนานุกรมข้อความส่วนกลางใน `apps/web/src/lib/locales/en.json` และเรียกผ่าน `locale.js` เฉพาะข้อความของแอป ไม่แปลชื่อที่ผู้ใช้กรอก
- ภาษาเริ่มต้นคือไทย จำภาษาบนอุปกรณ์ผ่าน `suth-language` การเปลี่ยนภาษาจะโหลดหน้าใหม่เพื่อให้ข้อความที่สร้างตอนเริ่มโมดูลเปลี่ยนพร้อมกัน ใช้การป้องกันข้อมูลที่ยังไม่บันทึกก่อนเปลี่ยนหน้า
- ขยาย ADR-0002 เฉพาะการแสดงผล: ภาษาไทยใช้ พ.ศ.; อังกฤษใช้ ค.ศ. และกำกับปีงบด้วย พ.ศ. เช่น FY 2026 (B.E. 2569) ขอบเขตยังเป็น ต.ค.–ก.ย. เงินยังเป็น THB และเดือนในฐานข้อมูลยังเป็น ค.ศ. `YYYY-MM`
- การจัดรูปแบบวันที่และปีงบอยู่ใน `packages/domain` ส่วน state ภาษาของเบราว์เซอร์อยู่ฝั่งเว็บ
- API คง Problem Details เดิม เพิ่มค่าประกอบข้อความเตือนโดยไม่เปลี่ยนความหมายฟิลด์เดิม ฝั่งเว็บใช้รหัสข้อผิดพลาดเพื่อแสดงข้อความอังกฤษที่ปลอดภัย

## ทางเลือกที่ไม่เลือก

ไม่แปลชื่อข้อมูลอัตโนมัติ เพราะทำให้ชื่ออ้างอิงระหว่างรายงานไม่ตรงกัน ไม่เปลี่ยนฐานข้อมูลหรือ framework เพื่อเพิ่มภาษา เพราะขอบเขตนี้เป็นเรื่องการแสดงผล

## ผลที่ตามมา

ข้อความใหม่ต้องมีคำแปลและทดสอบค่าประกอบข้อความทั้งสองภาษา ชื่อภาษาอังกฤษของหน่วยงานที่ต้องใช้เป็นทางการต้องมาจากเจ้าของข้อมูล ไม่เดาจากชื่อไทย ข้อผิดพลาดจาก API ที่ยังไม่มีคำแปลเฉพาะใช้ข้อความสำรองอังกฤษตามรหัส/สถานะ ไม่ส่งรายละเอียดระบบภายใน
