# 0029 — ผู้ดูแลทุกคนเห็นและทำต่องานนำเข้าของกันได้ ทุกการกระทำมีชื่อผู้ทำ

**สถานะ:** Accepted — ผู้ใช้อนุมัติแผนเมื่อ 2026-09-23 (#178)

## บริบท

งานนำเข้าค้างได้หลายวัน (รอเอกสารสัญญา รอตรวจชื่ออาคาร) ทีม IT มีไม่กี่คน ถ้าเห็นเฉพาะคนสร้าง งานของคนที่ลาจะค้าง
จนหมดอายุ และคนอื่นอัปโหลดไฟล์เดิมซ้ำโดยไม่รู้ว่ามีคนทำอยู่

## การตัดสินใจ

- **เฉพาะ role `admin`** — เหมือนการนำเข้าเดิม API ตอบ 403 กับ staff/viewer เมนูซ่อนเป็นแค่ความสะดวก (ADR-0006)
- **ผู้ดูแลทุกคนเห็นทุก session** — รายการแสดงเจ้าของ วันที่สร้าง ใช้ล่าสุด (ใคร เมื่อไร) และสถานะ
- **ผู้ดูแลคนใดก็ทำต่อได้** — แก้การตัดสินใจ สร้างสัญญา/ปีงบจากหน้านำเข้า บันทึก หรือยกเลิก เจ้าของไม่เปลี่ยน แต่ทุก
  การกระทำเขียนลงประวัติพร้อมผู้ทำ หน้าเว็บบอกเมื่อคนเปิดอยู่ไม่ใช่เจ้าของ
- **ประวัติเปิดดูได้ แก้ไม่ได้** — ไม่มี endpoint แก้หรือลบ event และ session ไม่ถูกลบ (หมดอายุแทน ADR-0027)
- **ไฟล์ต้นฉบับดาวน์โหลดคืนได้เฉพาะ admin** — ใช้ตรวจย้อนหลังว่าตัวเลขมาจากอะไร ไฟล์มีชื่อหน่วยงานและเลขเครื่อง
- **ที่มาของเครื่องและยอด** (`import_session_id`) แสดงรายละเอียด session เฉพาะ admin ผู้ใช้อื่นเห็นแค่ว่ามาจากการนำเข้า
- **ร่างของฟอร์มเพิ่มเครื่องเป็นของคนเดียว** (sessionStorage แยกตามผู้ใช้ ล้างเมื่อออกจากระบบ — #177) ไม่ใช่งานที่แบ่งกันทำ

## ทางเลือกที่ไม่เลือก

- **เห็นเฉพาะเจ้าของ** — งานค้างเมื่อเจ้าของไม่อยู่ และเกิดการนำเข้าไฟล์เดียวกันซ้ำหลาย session
- **ต้องโอนความเป็นเจ้าของก่อนทำต่อ** — เพิ่มขั้นตอนโดยไม่เพิ่มความรับผิดชอบ เพราะประวัติบันทึกผู้ทำทุกขั้นอยู่แล้ว
- **ให้ staff นำเข้ายอดมิเตอร์ได้** — ยอดพิมพ์คือฐานของทุกบาท การนำเข้าสร้างเครื่องและชื่อหลักได้ด้วย จึงคงไว้ที่ admin

## ผลที่ตามมา

- ถ้าวันหลังต้องแยกสิทธิ์ (เช่น staff นำเข้าได้เฉพาะยอด) ต้องเขียน ADR ใหม่และแยก endpoint ตามสิ่งที่เขียน
