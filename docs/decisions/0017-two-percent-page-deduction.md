# 0017 — หักจำนวนหน้าพิมพ์ 2% และใช้กับยอดย้อนหลังทุกปีงบ

**สถานะ:** Accepted — ข้อการปัดเงินเป็นสตางค์ต่อเครื่องต่อเดือน superseded by [ADR-0022](0022-round-at-invoice-line-and-allocate.md); กฎหัก 2% ที่จำนวนหน้ายังมีผล

## บริบท

โค้ดและกฎธุรกิจปัจจุบันใช้จำนวนหน้าดิบคูณ 0.8 ผู้ใช้แก้ requirement เป็นการหัก 2% จากจำนวนหน้า และยืนยันให้รายงานย้อนหลังทุกปีงบใช้สูตรนี้ด้วย

## การตัดสินใจที่ยืนยันแล้ว

- รับจำนวนหน้าดิบเป็นจำนวนเต็ม และคงค่าที่ผู้ใช้บันทึกไว้
- จำนวนหน้าสุทธิเท่ากับจำนวนหน้าดิบคูณ 0.98 เช่น 101 หน้าเหลือ 98.98 หน้า ไม่ปัดจำนวนหน้าสุทธิเป็นจำนวนเต็มก่อนคิดเงิน
- คูณจำนวนหน้าสุทธิด้วยราคาต่อหน้าที่ใช้จริง แล้วปัดเงินเป็นสตางค์ต่อเครื่องต่อเดือนก่อนรวมยอด โดยคงการปัดครึ่งขึ้นตาม Q16 เช่น 0.245 บาทเป็น 0.25 บาท
- ใช้สูตรนี้กับข้อมูลย้อนหลังทุกปีงบ ไม่กำหนดเดือนเริ่มใช้สูตรใหม่

ทางเลือกที่ไม่ได้เลือกคือการใช้ 2% เฉพาะตั้งแต่เดือนหนึ่งเป็นต้นไป ผู้ใช้เลือกให้ยอดย้อนหลังใช้กฎเดียวกันด้วย

## ผลและขอบเขต

ยอดสุทธิและค่าใช้จ่ายย้อนหลังจะเปลี่ยน แม้จำนวนหน้าดิบไม่เปลี่ยน การเปลี่ยน SQL views ต้องมี migration ที่ผ่านการอนุมัติตามกติกา repository; การยืนยัน requirement นี้ยังไม่ใช่การรัน migration หรือเปลี่ยน production

กฎราคาพิเศษเฉพาะเครื่องและการจัดยอดตามประวัติการย้ายยังใช้ความหมายที่ยืนยันแยกไว้ใน Q13 และ [ADR-0014](0014-resolve-overlapping-location-history.md)
