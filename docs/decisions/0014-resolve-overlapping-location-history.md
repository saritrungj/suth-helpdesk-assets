# 0014 — เลือกประวัติตำแหน่งที่มีผลเพียงช่วงเดียวต่อเดือน

**สถานะ:** Accepted

## บริบท

รายงานย้อนหลังต้องใช้สถานที่และหน่วยงานที่เครื่องสังกัดในเดือนนั้น แต่ฐาน MariaDB
ปัจจุบันไม่ได้บังคับไม่ให้ช่วงใน `device_location_history` ซ้อนกัน หาก join ทุกช่วง
ที่ตรงกัน ยอดพิมพ์หนึ่งรายการจะกลายเป็นหลายแถวและทำให้ยอดหน้าและค่าใช้จ่ายถูกบวกซ้ำ

## การตัดสินใจ

ทุก query รายงานเรียกกฎเดียวจาก `apps/api/src/shared/effective-location-sql.js` เพื่อ
เลือกประวัติได้ไม่เกินหนึ่งแถวต่อเครื่องและเดือน:

1. พิจารณาเฉพาะช่วงที่เดือนอยู่ตั้งแต่ `effective_from` และก่อน `effective_to`
2. ถ้ามีหลายช่วง ให้ช่วงที่ `effective_from` ล่าสุดชนะ
3. ถ้าวันเริ่มเท่ากัน ให้แถวที่ `id` มากกว่าชนะ เพื่อให้ผลลัพธ์คงที่
4. ถ้าไม่พบประวัติ ใช้สถานที่และหน่วยงานปัจจุบันจาก `devices`

กฎนี้ใช้กับการจัดกลุ่ม การกรอง และการแสดงตำแหน่ง ห้าม join ประวัติโดยตรงแล้วนำทุกแถว
ไปรวมยอด

## ผลที่ตามมา

รายงานไม่บวกยอดซ้ำแม้ข้อมูลเก่ามีช่วงซ้อนกัน และทุกหน้าตีความข้อมูลผิดรูปแบบเหมือนกัน
อย่างไรก็ตาม ทางเขียนข้อมูลยังต้องกันช่วงซ้อนใน API เพราะกฎนี้เพียงทำให้การอ่านมีผล
ที่แน่นอน ไม่ได้ซ่อมข้อมูลต้นทางหรือเพิ่ม constraint ในฐานข้อมูล
