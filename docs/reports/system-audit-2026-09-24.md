
## 6. ฐานข้อมูลและความถูกต้องของข้อมูล

ข้อสังเกต: `print_transactions.device_id` ซ้ำกับ `device_meter.device_id` (denormalized — ตรงกันทุกแถวตอนนี้ ควรคงไว้พร้อมเทส) · ไม่มี audit (F05) · สำรองผิดฐาน (F01)

## 7. ความปลอดภัย

ผ่าน: สิทธิ์ที่ API (ตรวจจริง 23 คำขอ × 3 บทบาท) · JWT ใน cookie httpOnly SameSite=Lax · bcrypt · login rate limit 10 ครั้ง/15 นาที · helmet · CORS แบบรายชื่อ · SQL parameterized (จุด interpolate เป็นชื่อคอลัมน์จาก whitelist/zod enum) · อัปโหลดจำกัดนามสกุล/MIME/5 MB + จำกัดขนาดหลังคลาย (#207) · ไม่ส่ง hash รหัสผ่าน · ปิดบัญชี/ลดสิทธิ์/เปลี่ยนรหัสมีผลทันที (#208) · `npm audit` 0
ต้องแก้: F02 (error leakage) · F09 (Needs Verification) · F12 (P3)

## 8. UI/UX

ผ่าน: ทุกหน้ามีหัวข้อ ไม่มี error ใน console ไม่มีคำขอล้ม ไม่ล้นแนวนอนที่ 390px · สถานะ loading/empty/error มีทุกหน้า · ปุ่มเขียนซ่อนตามสิทธิ์ถูกต้อง

## 9. สถาปัตยกรรมและหนี้ทางเทคนิค
