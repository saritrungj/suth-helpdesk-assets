# นำเข้าไฟล์จากผู้ให้เช่า

ใช้เมื่อได้รายงานมิเตอร์หรือรายงานสถานะเครื่องจากผู้ให้เช่า แล้วต้องการลงทะเบียนเครื่องและจำนวนพิมพ์รายเดือนในครั้งเดียว

สำหรับ **ผู้ดูแลระบบ** เท่านั้น ระบบรับไฟล์ `.xlsx` `.xls` `.csv` ขนาดไม่เกิน 5 MB

## สามข้อที่ต้องรู้ก่อน

1. **ยังไม่มีอะไรเข้าระบบจนกว่าจะกด "ยืนยันบันทึก N รายการ"** สัญญา ปีงบ ชื่อ เครื่อง และตัวเลขที่ระบบเตรียมให้เป็นแผนเท่านั้น ยกเลิกงานแล้วไม่มีอะไรค้าง
2. **ทั้งไฟล์บันทึกพร้อมกันหรือไม่บันทึกเลย** ไฟล์ที่มีข้อผิดพลาดแม้จุดเดียวไม่ถูกบันทึกเลยสักแถว เพราะไฟล์หนึ่งชุดคือจำนวนพิมพ์ของงวดเดียวกันทั้งชุด
3. **ไฟล์หนึ่งไฟล์คือหนึ่ง "งานนำเข้า"** เก็บอยู่บนเซิร์ฟเวอร์ ปิดหน้า ออกจากระบบ หรือให้ผู้ดูแลระบบคนอื่นทำต่อได้จากรายการ "งานนำเข้าที่ยังไม่เสร็จ" ไม่ต้องอัปโหลดใหม่ งานที่ไม่มีใครแตะ 14 วันจะหมดอายุ

## ก่อนอัปโหลด

- ใช้ไฟล์ของผู้ให้เช่าตรงๆ ไม่ต้องแปลงเป็นเทมเพลต
- เปิดดูว่าภาษาไทยอ่านออก ไม่เป็นตัวยึกยือ
- ตรวจว่าไม่มีข้อมูลส่วนบุคคลที่ไม่เกี่ยวข้องติดมา
- ตัวเลขเป็นตัวเลขจริง ไม่ใช่ข้อความที่มีเครื่องหมายจุลภาค
- ไม่มีไฟล์ของผู้ให้เช่า: ปุ่ม **ไฟล์ตัวอย่าง** ให้เทมเพลต **ทะเบียนเครื่อง** และ **จำนวนพิมพ์รายเดือน** เทมเพลตจำนวนพิมพ์มีหัวคอลัมน์ของสามเดือนล่าสุด ต้องแก้เป็นเดือนที่จะนำเข้าจริง

ไฟล์ที่ระบบรับและชื่อหัวคอลัมน์ทั้งหมดอยู่ที่ [รูปแบบไฟล์นำเข้า](../reference/import-format.md)

## ขั้นตอน

1. เมนู **งานประจำ** → **นำเข้าไฟล์จากผู้ให้เช่า** (หน้า บันทึกจำนวนพิมพ์รายเดือนมีไอคอนนำเข้าข้างช่อง ดูเดือน พามาที่เดียวกัน)
2. เลือกว่าจะให้ระบบช่วยเตรียมไหม ช่อง **ให้ระบบเตรียมข้อมูลที่ขาดให้ แล้วแสดงก่อนบันทึก** เปิดไว้เป็นค่าเริ่มต้น และควรเปิด ระบบจะเตรียมสัญญาจากหัวรายงาน ปีงบ ยี่ห้อ อาคาร ฝ่าย และหมวดมิเตอร์ของรุ่นที่รู้จัก แต่ **ยังไม่บันทึก** ต้องเลือกช่องนี้ก่อนอัปโหลด
3. ลากไฟล์มาวางในกรอบ หรือกด **เลือกไฟล์จากเครื่อง** ไฟล์ใหญ่อาจใช้เวลาราวครึ่งนาที ระบบพาไปหน้าของงานนั้นเอง
4. อ่าน **สิ่งที่ต้องทำก่อนบันทึก** รายการเรียงตามลำดับที่ควรทำ (ดูตารางสถานะด้านล่าง)
5. ทำทีละข้อตามหัวข้อ [แก้เรื่องที่ระบบหยุดถาม](#แก้เรื่องที่ระบบหยุดถาม) ทุกครั้งที่เลือก ระบบบันทึกตัวเลือกและตรวจไฟล์ใหม่เอง ขั้นตรวจไม่เขียนอะไรลงข้อมูลจริง
6. ถ้ายังเหลือหลายข้อ กด **ให้ระบบเลือกส่วนที่เหลือ** ให้ระบบเลือกเท่าที่ทำได้ ข้อที่ยังต้องให้คุณดูจะขึ้นเป็น "หยุดให้คุณดูก่อนบันทึก N เรื่อง"
7. เมื่อไม่มีข้อค้าง ตรวจกล่อง **สรุปก่อนยืนยัน** (อยู่ด้านข้างบนจอกว้าง ใต้เนื้อหาบนจอแคบ) แล้วกด **ดูรายละเอียดก่อนยืนยัน** อ่านกล่อง "เมื่อกดยืนยัน ระบบจะ" ให้ครบ ถ้ากล่องขึ้น "กำลังบันทึกการเลือกและตรวจใหม่…" ให้รอ ปุ่มยืนยันกดไม่ได้จนกว่าตรวจเสร็จ ถ้าขึ้น "ตรวจตัวเลือกใหม่ไม่สำเร็จ — กดตรวจอีกครั้ง" ให้กด **ตรวจอีกครั้ง**
8. กด **ยืนยันบันทึก N รายการ** แล้วยืนยันอีกครั้งในกล่อง "ยืนยันบันทึกงานนำเข้านี้" ขึ้น "บันทึกงานนำเข้าเรียบร้อย"

### สถานะของแต่ละข้อใน "สิ่งที่ต้องทำก่อนบันทึก"

| ที่เห็น | แปลว่า |
|---|---|
| แถบแดง | ต้องทำก่อน ไม่งั้นกดยืนยันไม่ได้ |
| แถบเหลือง | บันทึกได้ แต่ควรตรวจก่อน |
| ไอคอนนาฬิกา | รอข้อก่อนหน้าทำเสร็จ |
| เครื่องหมายถูก | เรียบร้อย |

ปุ่มท้ายแต่ละข้อ (เช่น **เลือกชื่อ** **เลือกหมวด** **สร้างสัญญาจากไฟล์**) พาไปส่วนของหน้าที่ต้องแก้

### อ่านกล่อง "เมื่อกดยืนยัน ระบบจะ"

ตัวเลขทุกตัวมาจากการลองบันทึกแล้วย้อนกลับ ตรงกับสิ่งที่จะเกิดจริง

| บรรทัด | แปลว่า |
|---|---|
| สร้างสัญญา … / สร้างปีงบ … | สัญญาและปีงบใหม่ที่จะเกิด ตรวจวันที่ ค่าเช่า VAT และราคากับเอกสารสัญญา |
| เพิ่มยี่ห้อ/อาคาร/ฝ่าย/ชั้น/แผนกใหม่ … และ จำชื่อเรียกอื่นของ … | ชื่อที่ไม่เคยมีในระบบ และชื่อที่คุณบอกว่าเป็นชื่อเรียกอื่นของรายการเดิม |
| ลงทะเบียนเครื่องใหม่ N เครื่อง / เติมช่องที่ว่างของเครื่องเดิม N เครื่อง | เครื่องที่เพิ่มและเครื่องที่ถูกเติมเฉพาะช่องว่าง ไม่ย้ายเครื่องและไม่ทับค่าเดิม |
| บันทึกยอดใหม่ N รายการ | จำนวนพิมพ์ของเดือนที่ยังไม่เคยมีตัวเลข |
| **แทนที่ยอดเดิม N รายการ** (สีเหลือง) | จำนวนพิมพ์ที่มีอยู่แล้ว ถูกเปลี่ยนเป็นค่าในไฟล์ ตรวจให้แน่ใจก่อนยืนยัน |
| เลขซีเรียลคล้ายเครื่องที่มีอยู่ … (สีเหลือง) | ดูหัวข้อด้านล่าง |
| ยอดตามใบแจ้งหนี้ของระบบหลังบันทึก … | เงินตามใบแจ้งหนี้ที่ระบบคำนวณได้หลังบันทึก ใช้เทียบกับท้ายรายงานของผู้ให้เช่า |

## แก้เรื่องที่ระบบหยุดถาม

หา "ข้อความบนหน้าจอ" ในตาราง แล้วทำตามช่องขวา ข้อความที่ขึ้นต้นเหมือนกันแต่ต่างที่ชื่อหรือตัวเลข เป็นเรื่องเดียวกัน

### สัญญา

| ข้อความบนหน้าจอ | แปลว่า | ทำอย่างไร |
|---|---|---|
| **ยังไม่มีสัญญา (เลขที่) ในระบบ** | ไฟล์อ้างสัญญาที่ยังไม่มีให้เทียบ | ส่วน **สัญญา** มีฟอร์มที่เติมจากหัวไฟล์แล้ว ตรวจ **เริ่มสัญญา** **สิ้นสุดสัญญา** **ค่าเช่าคงที่ต่อเดือน** **อัตรา VAT** และราคาต่อหน้าของทุกหมวดกับเอกสารสัญญา แล้วกด **ใช้สัญญานี้ — สร้างเมื่อยืนยัน** เปลี่ยนใจกด **ไม่สร้างสัญญานี้** แก้กด **แก้** แล้ว **เก็บการแก้** ได้จนกว่าจะยืนยัน |
| ใต้ฟอร์มสัญญา: **เลือกหมวดมิเตอร์ของทุกรุ่นก่อน ราคาต่อหน้าจึงจะขึ้นครบ** | ปุ่มสร้างสัญญายังกดไม่ได้ เพราะราคาต่อหน้าขึ้นตามหมวดของรุ่น | ไปเลือกหมวดที่ส่วน **ชื่อที่ไม่รู้จักและหมวดมิเตอร์** ก่อน |
| ใต้ฟอร์มสัญญา: **ต้องมีราคาต่อหน้าอย่างน้อยหนึ่งหมวด** | สัญญาที่ไม่มีราคาสร้างไม่ได้ | กรอกราคาต่อหน้าจากเอกสารสัญญา |
| ในฟอร์ม: **ไฟล์มีหลายราคาในหมวดนี้: …** | มีสองราคาในหมวดเดียว มักเป็นหมวดของรุ่นผิดหรือมีราคาพิเศษเฉพาะเครื่อง | ตรวจหมวดของรุ่นที่ส่วน **ชื่อที่ไม่รู้จักและหมวดมิเตอร์** และตรวจเอกสารสัญญา แล้วกรอกราคาที่ถูก |
| **สัญญา (เลขที่) ในระบบไม่ตรงกับไฟล์** (แดง) — ค่าเช่าหรือ VAT ต่างกัน | สัญญาในระบบกับไฟล์ไม่ตรงกัน เงินตามใบแจ้งหนี้จะไม่ตรงกับของผู้ให้เช่า | ดูค่าทั้งสองฝั่ง ถ้าไฟล์ถูกและสัญญาในระบบผิด กด **ไปหน้าสัญญา** แก้ แล้วกลับมากด **ตรวจอีกครั้ง** (งานรออยู่ที่เดิม) ถ้าความต่างถูกต้อง เช่นมีบันทึกแก้ไขสัญญา พิมพ์เหตุผลอย่างน้อย 3 ตัวอักษรในช่อง **ยอมรับความต่างนี้ เพราะ…** เหตุผลถูกเก็บในประวัติของงาน |
| **สัญญา (เลขที่): มีข้อที่ควรตรวจ** (เหลือง) — อายุสัญญาต่างกัน | อายุสัญญาในไฟล์ต่างจากในระบบ งวดนอกอายุสัญญาในระบบจะหาราคาไม่ได้ | ถ้าไฟล์ถูก แก้อายุสัญญาที่หน้าสัญญา แล้วกด **ตรวจอีกครั้ง** ข้อนี้ไม่มีช่องยอมรับ |

### ชื่อและหมวดมิเตอร์

| ข้อความบนหน้าจอ | แปลว่า | ทำอย่างไร |
|---|---|---|
| **ยังต้องเลือกชื่อยี่ห้อ/อาคาร/ฝ่ายที่ไม่รู้จัก N ชื่อ** | ชื่อในไฟล์ไม่ตรงชื่อหรือชื่อเรียกอื่นที่ระบบมี | ส่วน **ชื่อที่ไม่รู้จักและหมวดมิเตอร์** เลือกที่กล่องของแต่ละชื่อ: **สร้าง…ใหม่ชื่อนี้** (ช่องชื่อใต้กล่องแก้เป็นชื่อทางการได้) หรือ **ชื่อเรียกอื่นของ …** แล้วเลือกรายการที่มีอยู่ ระบบจำไว้ ไฟล์ครั้งหน้าไม่ต้องเลือกซ้ำ กด **สร้างใหม่ทุกชื่อที่ยังไม่เลือก** เมื่อทุกชื่อที่เหลือเป็นของใหม่จริง |
| **ยี่ห้อ/อาคาร/ฝ่าย "(ชื่อ)" คล้าย "(ชื่อในระบบ)" ที่มีในระบบ — เลือกเองว่าเป็นที่เดียวกันหรือไม่** | ระบบไม่เดาให้ เพราะชื่อใกล้กันแต่ไม่แน่ใจว่าเป็นที่เดียวกัน | ที่เดียวกัน → **ชื่อเรียกอื่นของ (ชื่อในระบบ)** คนละที่ → **สร้าง…ใหม่ชื่อนี้** |
| **ยังต้องเลือกหมวดมิเตอร์ของรุ่นใหม่ N รุ่น** / **ไม่รู้หมวดมิเตอร์ของรุ่น … — หมวดกำหนดราคาต่อหน้า จึงต้องเลือกเอง** | รุ่นนี้ไม่อยู่ในแคตตาล็อกของระบบ และหมวดเป็นตัวกำหนดราคาต่อหน้า | เลือกหมวดที่กล่อง **หมวดมิเตอร์ของแต่ละรุ่น** และติ๊ก **มีมิเตอร์สี** ถ้ารุ่นนี้มีมิเตอร์สี เลือกผิดแปลว่าราคาของทั้งรุ่นผิด ถ้าไม่แน่ใจ ถามผู้ให้เช่าหรือดูเอกสารสัญญา |
| **ชื่อที่ตั้งใช้ไม่ได้** | ชื่อที่พิมพ์ซ้ำหรือผิดกติกา | ข้อความใต้บรรทัดบอกเหตุผล แก้ชื่อที่ช่องใต้กล่องเลือก |

### ปีงบ

| ข้อความบนหน้าจอ | แปลว่า | ทำอย่างไร |
|---|---|---|
| **ยังไม่มีปีงบ … ที่ครอบเดือนในไฟล์** (เหลือง) | บันทึกได้ แต่รายงานของปีงบนั้นเปิดไม่ได้จนกว่าจะสร้างปีงบ | กด **สร้างปีงบเมื่อยืนยัน** |

### เครื่อง

| ข้อความบนหน้าจอ | แปลว่า | ทำอย่างไร |
|---|---|---|
| **เครื่อง: รอสร้างสัญญาก่อน** | ยังนับเครื่องไม่ได้เพราะรอสัญญา | ทำส่วนสัญญาก่อน |
| **เครื่อง: สร้างใหม่ N · เติมข้อมูล N · ไม่เปลี่ยน N · ข้าม N** | ข้ามคือแถวที่ข้อมูลใช้ไม่ได้ แถวอื่นยังบันทึกได้ | ดูตาราง **แถวที่ต้องดู** (แผ่นงาน แถว Serial อาคาร ผล เหตุผล) แถวที่ข้ามไม่ถูกนำเข้า ถ้าต้องการ แก้ไฟล์แล้วอัปโหลดเป็นงานใหม่ |
| **คำเตือนของทะเบียน N รายการ** รวมถึง **เลขซีเรียลคล้ายเครื่องที่มีอยู่** | Serial ต่างจากเครื่องในทะเบียนนิดเดียว เช่นสลับตัวอักษรหรือ O กับ 0 | ถ้าเป็นเครื่องเดียวกันที่พิมพ์ผิด **อย่าบันทึก** เพราะจะได้เครื่องซ้ำ แก้ Serial ในไฟล์ให้ตรงทะเบียนแล้วอัปโหลดใหม่ ถ้าเป็นคนละเครื่องจริงบันทึกได้ |
| เครื่องใหม่ที่ขึ้น **รอตรวจยืนยันการติดตั้ง** | ไฟล์ไม่บอกว่าเครื่องติดตั้งแล้วหรือยัง | บันทึกได้ ยืนยันภายหลังที่หน้า **ตรวจยืนยันการติดตั้ง** (เข้าจากคำเตือนบนหน้าภาพรวม หรือกด Ctrl+K แล้วค้นหา) |

### เลขมิเตอร์และเงินตามใบแจ้งหนี้

| ข้อความบนหน้าจอ | แปลว่า | ทำอย่างไร |
|---|---|---|
| **ยอดมิเตอร์: รอให้ข้อมูลเครื่องพร้อมก่อน** | ตรวจตัวเลขได้หลังชื่อ หมวดมิเตอร์ และสัญญาครบ | ทำข้อก่อนหน้าให้ครบ |
| **มี N รายการต้องแก้ก่อน — ทั้งไฟล์ยังบันทึกไม่ได้** (แดง) | มีแถวที่ตัวเลขหรือเครื่องใช้ไม่ได้ | อ่านรายการเหตุผล (แสดง 20 รายการแรก) กด **ดาวน์โหลดรายการ (CSV)** เพื่อดูครบ แก้ตามตารางด้านล่าง แล้วอัปโหลดไฟล์ที่แก้เป็นงานใหม่ |
| **ยอดตามใบแจ้งหนี้ต่างจากท้ายแผ่น N งวด** (เหลือง) | เงินที่ระบบคำนวณไม่ตรงกับผลรวมท้ายรายงาน ต่างไม่เกิน 1 สตางค์ต่องวดถือว่าตรง | ดูตาราง **เงินตามใบแจ้งหนี้เทียบกับท้ายรายงาน** แถวที่ต่างขึ้นสีเหลือง ตรวจค่าเช่า VAT และราคาในสัญญา หรือเลขที่ผู้ให้เช่าแก้มือในไฟล์ |
| ช่องสรุป **เขียนทับค่าเดิม** (เหลืองเมื่อมี) และตาราง **ค่าที่จะถูกเขียนทับ** | จำนวนพิมพ์ที่มีอยู่แล้ว จะถูกแทนที่ด้วยค่าในไฟล์ | ดู Serial เดือน ค่าเดิม ค่าใหม่ (10 แถวแรก กด **แสดงทั้งหมด** หรือ **ดาวน์โหลด CSV**) ถ้าค่าใหม่ถูก กดยืนยันได้ ถ้าไม่ถูก ยกเลิกงานแล้วแก้ไฟล์ |
| **ไม่มีอะไรใหม่ในไฟล์นี้** (แดง) | ทุกเครื่องและตัวเลขในไฟล์มีในระบบด้วยค่าเดียวกันแล้ว | ไม่ต้องบันทึก กด **ยกเลิกงานนี้** |

#### เหตุผลที่ตัวเลขใช้ไม่ได้ ("มี N รายการต้องแก้ก่อน")

| เหตุผลที่เห็น | ทำอย่างไร |
|---|---|
| ไม่พบเครื่อง SN "…" ในทะเบียน — ในทะเบียนมี "…" ตรวจว่าพิมพ์ผิดหรือไม่ | Serial ในไฟล์พิมพ์ผิด แก้ให้ตรงตามที่ระบบเสนอ |
| ไม่พบเครื่อง SN "…" ในทะเบียน — ลงทะเบียนเครื่องก่อน | เครื่องยังไม่อยู่ในทะเบียน นำเข้ารายงานสถานะเครื่องก่อน หรือเพิ่มเครื่องที่หน้า ทะเบียนเครื่องพิมพ์ |
| Serial และเดือนนี้ซ้ำกันในไฟล์ / มิเตอร์และงวดนี้ซ้ำกันในไฟล์ | เครื่องเดียวมีตัวเลขเดือนเดียวกันสองแถว ระบบไม่เลือกให้ ลบแถวที่ไม่ใช่ออกจากไฟล์ |
| จำนวนพิมพ์ต้องเป็นจำนวนเต็มตั้งแต่ 0 ถึง 1,000,000 | ค่าไม่ใช่ตัวเลข ติดลบ หรือเกินเพดาน แก้ในไฟล์ |
| เลขสิ้นงวด … น้อยกว่าเลขต้นงวด … / เลขมิเตอร์ต้องเป็นจำนวนเต็มไม่ติดลบ / จำนวนพิมพ์ … หน้าสูงผิดปกติ | เลขมิเตอร์ในไฟล์ผิดหรือเครื่องถูกเปลี่ยนกลางงวด สอบถามผู้ให้เช่า |
| ไฟล์มีแถวมิเตอร์สีของเครื่องนี้ แต่ในทะเบียนเครื่องนี้ไม่มีมิเตอร์สี | เปิด **แก้ไข** เครื่องในทะเบียน ติ๊ก **เครื่องนี้มีมิเตอร์สี** แล้วตรวจอีกครั้ง |
| เครื่องนี้มีสองแถว (ขาวดำและสี) แต่ไม่มีราคาในคอลัมน์ Cost/Click … | ใส่ราคาในคอลัมน์ Cost/Click ให้ทั้งสองแถว ระบบแยกมิเตอร์สีจากราคา ไม่ใช่จากลำดับแถว |
| เลขเครื่องนี้มีเกินสองแถวในแผ่นเดียว (ขาวดำหนึ่ง สีหนึ่ง) | ลบแถวที่เกิน |
| ราคาในไฟล์ … ไม่ตรงกับราคาในระบบ … — ตรวจหมวดมิเตอร์ของเครื่องหรือราคาในสัญญา | ตรวจ **หมวดมิเตอร์** ของเครื่อง และราคาของหมวดนั้นในสัญญา |
| ไฟล์เป็นของสัญญา … แต่ในระบบเครื่องนี้คิดเงินใต้สัญญา … | เครื่องผูกสัญญาผิดฉบับ หรือไฟล์ผิดฉบับ ตรวจที่ **แก้ไข** เครื่อง ส่วน **สัญญาที่ผูกอยู่** และ **เริ่มคิดเงินตามสัญญานี้ตั้งแต่วันที่** ตรวจเอกสารก่อนแก้ เพราะมีผลกับข้อมูลย้อนหลัง |
| อ่านงวดจากหัวแผ่นไม่ได้ (ต้องมีวันที่สิ้นงวด …) | หัวแผ่นต้องมีวันที่สิ้นงวด เช่น "to Aug 23, 2569" |
| หาคอลัมน์ "SN." หรือหัวตาราง "Meter Start/Meter End" ไม่เจอ | ไฟล์ไม่ใช่รูปแบบที่รับ ตรวจ [รูปแบบไฟล์นำเข้า](../reference/import-format.md) |

คำเตือน "เลขต้นงวด … ไม่เท่าเลขสิ้นงวด … ของงวด …" ไม่บล็อกการบันทึก แต่ควรสอบถามผู้ให้เช่าว่างวดนั้นขาดหายหรือไม่

## หลังบันทึก

หน้างานแสดง "บันทึกแล้วเมื่อ …" พร้อมจำนวนเครื่องใหม่ เติมข้อมูล ตัวเลขใหม่ และแทนที่

1. กด **ดูภาพรวมปีงบ …** หรือ **ค่าใช้จ่าย** ตรวจว่าตัวเลขขึ้นในปีงบที่ถูก
2. เทียบเงินตามใบแจ้งหนี้กับยอดรวมท้ายรายงาน ต่างได้ไม่เกิน 0.01 บาทต่องวด เพราะผู้ให้เช่าปัดเศษ VAT
3. **ประวัติของงานนี้** บอกว่าใครทำอะไรเมื่อไร และปุ่ม **ไฟล์ต้นฉบับ** ดาวน์โหลดไฟล์ที่นำเข้า เครื่องและตัวเลขที่มาจากงานนี้เก็บเลขงานไว้ ถ้ามีคนแก้ตัวเลขด้วยมือภายหลัง ความเชื่อมโยงนั้นหาย

นำเข้าไฟล์เดิมซ้ำได้ เครื่องที่มีแล้วไม่ถูกสร้างซ้ำ ระบบเติมเฉพาะช่องที่ยังว่าง ไม่ย้ายเครื่อง และตัวเลขที่ค่าเท่าเดิมนับเป็น "ไม่เปลี่ยน" ถ้าเปิดไฟล์เดิมที่เคยบันทึกแล้ว หน้างานบอก "ไฟล์นี้เคยบันทึกแล้วในงาน #N" พร้อมปุ่ม **ดูงานนั้น**

> ช่องที่เว้นว่างในไฟล์แปลว่า **ไม่เปลี่ยนข้อมูลเดิม** ส่วน `0` เป็นค่าจริงที่แปลว่าเดือนนั้นไม่มีการพิมพ์ สองอย่างนี้ไม่เหมือนกัน

## ยกเลิก ทำต่อ และลบงาน

| สถานการณ์ | ทำอย่างไร |
|---|---|
| ไม่ต้องการบันทึกไฟล์นี้ | กด **ยกเลิกงานนี้** ยืนยัน ไฟล์และประวัติยังเก็บไว้ แต่บันทึกต่อไม่ได้ และไม่มีสัญญา ปีงบ ชื่อ หรือเครื่องจากไฟล์นี้ค้างในระบบ |
| ปิดหน้าไปก่อน | กลับมาที่ **นำเข้าไฟล์จากผู้ให้เช่า** งานอยู่ในรายการ "งานนำเข้าที่ยังไม่เสร็จ" กด **ทำต่อ** (สถานะ ต้องทำต่อ / พร้อมบันทึก / ล้มเหลว) หรือติ๊ก **แสดงงานที่ปิดแล้ว** ดูทั้งหมด |
| งานของผู้ดูแลระบบคนอื่น | ทำต่อได้ ขึ้น "งานนี้เป็นของ … — คุณทำต่อได้" ทุกการกระทำบันทึกในประวัติด้วยชื่อของคุณ |
| ขึ้น "ไฟล์เดียวกันเปิดอยู่ในงาน #N ของ …" | มีงานของไฟล์นี้อยู่แล้ว กด **ไปที่งานนั้น** อย่าเปิดซ้ำ |
| สถานะ **ล้มเหลว** | ข้อความสีแดงบอกสาเหตุ แก้แล้วกด **ตรวจอีกครั้ง** |
| มีคนแก้ข้อมูลที่เกี่ยวข้องระหว่างที่ตรวจ (ประวัติขึ้น "ข้อมูลเปลี่ยนระหว่างตรวจ — ไม่ได้บันทึก") | ระบบไม่แทนที่ค่าที่คุณไม่เคยเห็น หน้าโหลดผลล่าสุดมาให้ อ่านสรุปใหม่แล้วกดยืนยันอีกครั้ง |
| งานหมดอายุหรือยกเลิกและไม่เคยบันทึก | กด **ลบถาวร** ในหน้างานได้ ไม่กระทบเครื่องหรือจำนวนพิมพ์ในระบบ |
