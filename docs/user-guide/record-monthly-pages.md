# บันทึกจำนวนพิมพ์รายเดือน

ทำทุกเดือนหลังอ่านมิเตอร์ของเครื่อง ตัวเลขที่บันทึกที่นี่เป็นฐานของทุกรายงานและทุกบาทของค่าใช้จ่าย กรอกผิดหนึ่งช่อง ค่าใช้จ่ายของทั้งแผนกเพี้ยนตาม

สำหรับ **เจ้าหน้าที่** และ **ผู้ดูแลระบบ** บทบาท "ดูอย่างเดียว" เห็นหน้านี้ได้แต่กรอกไม่ได้ (หน้าจะขึ้น "บัญชีของคุณดูได้อย่างเดียว แก้ไขไม่ได้")

## เตรียมตัวเลขให้ถูกก่อนกรอก

**จำนวนพิมพ์** คือจำนวนหน้าที่เครื่องพิมพ์ **ในงวดนั้น** ไม่ใช่เลขที่ขึ้นบนหน้าปัดมิเตอร์

> จำนวนพิมพ์ = เลขมิเตอร์สิ้นงวด − เลขมิเตอร์ต้นงวด

งวดคือรอบคิดเงินของสัญญา และนับเป็นเดือนที่งวดสิ้นสุด สัญญาส่วนใหญ่ตัดรอบสิ้นเดือน แต่บางสัญญาตัดกลางเดือน เช่น 24 ก.ค. ถึง 23 ส.ค. นับเป็นเดือนสิงหาคม ให้ใช้เลขมิเตอร์ ณ วันตัดรอบของสัญญานั้น ไม่ใช่สิ้นเดือนปฏิทิน (นิยามเต็มอยู่ที่ [คำศัพท์โดเมน](../../CONTEXT.md))

ตัวอย่าง: เลขมิเตอร์ต้นงวด 120,400 สิ้นงวด 121,150 → กรอก **750**

สามข้อที่ต้องรู้ก่อนกด บันทึก:

1. **ระบบกันเลขสะสมได้เฉพาะที่เกิน 1,000,000 หน้า** ถ้ากรอกเลขมิเตอร์สะสมของเครื่องที่ยังต่ำกว่านั้น ระบบรับและรายงานของเดือนนั้นจะผิดทั้งเดือน ตรวจจากคอลัมน์เดือนก่อนหน้าที่อยู่ข้างช่องกรอกว่าตัวเลขอยู่ในระดับเดียวกัน (เดือนแรกของปีงบคอลัมน์นี้ว่าง ดูด้านล่าง)
2. **ช่องกรอกคือมิเตอร์ขาวดำของเครื่อง** เครื่องที่มีมิเตอร์สี ตัวเลขมิเตอร์สีเข้าทางไฟล์ของผู้ให้เช่าเท่านั้น (ดู [นำเข้าไฟล์จากผู้ให้เช่า](import-lessor-file.md)) อย่ากรอกจำนวนหน้ารวมสีลงช่องนี้
3. **`0` กับช่องว่างไม่เหมือนกัน**
   - `0` = อ่านมิเตอร์แล้ว เดือนนี้เครื่องไม่ได้พิมพ์ นับเป็น "กรอกแล้ว"
   - ว่าง = ยังไม่ได้อ่าน ไม่นับเป็น "กรอกแล้ว" และไม่ถูกนับเป็นศูนย์ในรายงาน

## กรอกทีละเดือน หลายเครื่อง

1. เมนูซ้ายหมวด **งานประจำ** → **บันทึกจำนวนพิมพ์** หัวหน้าเขียนว่า "บันทึกจำนวนพิมพ์รายเดือน"
2. ตรวจปุ่ม **ปีงบ** บนแถบบนสุดว่าเป็นปีงบที่ต้องการ
3. ตรวจปุ่มสลับด้านขวาบนว่าอยู่ที่ **กรอกรายเดือน** (เจ้าหน้าที่และผู้ดูแลระบบเปิดมาที่โหมดนี้เอง)
4. ช่อง **ดูเดือน** ระบบเลือกให้เป็นเดือนที่ค้างนานที่สุดที่ผ่านไปแล้ว ถ้าไม่มีเดือนค้างจะเป็นเดือนล่าสุดที่จบแล้ว เปลี่ยนเป็นเดือนอื่นได้จากช่องนี้ ถ้าเลือก **ทั้งปีงบ** จะไม่มีตารางกรอก
5. หาเครื่องที่จะกรอก
   - ช่อง **ค้นหา** รับ Serial รุ่น ตำแหน่ง แผนก หรือเลขที่สัญญา
   - ตัวกรอง **สถานะการกรอก** ในโหมดนี้ **ยังไม่กรอก** หมายถึงเครื่องที่ยังไม่มีตัวเลขของเดือนที่เลือก ส่วน **กรอกบางเดือน** กับ **ครบแล้ว** นับทั้งปีงบ
   - ตัวกรองอื่น: อาคาร ชั้น ฝ่าย แผนก ยี่ห้อ สถานะเครื่อง สัญญา
6. กรอกตัวเลขในช่องคอลัมน์ขวาสุด หัวคอลัมน์เป็นชื่อเดือนที่เลือก คอลัมน์ติดกันแสดงตัวเลขของเดือนก่อนหน้าไว้เทียบ ("—" แปลว่าเดือนก่อนยังไม่มีตัวเลข) **เดือนแรกของปีงบ (ตุลาคม) คอลัมน์นี้ขึ้น "เดือนก่อนหน้า" และ "—" ทุกแถวเสมอ** เพราะระบบไม่ดึงเดือนของปีงบก่อน ให้เทียบกับเดือนกันยายนเอง
7. แถวที่แก้แล้วขึ้น **แก้ไขแล้ว** และเปลี่ยนสีพื้น
8. ดูแถบล่างสุดที่ขึ้นเมื่อมีตัวเลขที่แก้ไว้ เขียนว่า "แก้ไว้ N รายการ · เดือน …" แล้วกด **บันทึก N รายการ** ขึ้นข้อความ "บันทึกแล้ว"
9. ไม่ต้องการที่แก้ไว้: กด **ทิ้งที่แก้ไว้**

ระบบส่งเฉพาะช่องที่คุณแก้ ช่องที่ไม่ได้แตะไม่ถูกเปลี่ยน และตัวเลขที่แก้ไว้ไม่หายเมื่อเปลี่ยนหน้าของตาราง บันทึกแล้วดูผลได้ที่ **ภาพรวมการพิมพ์** และ **ค่าใช้จ่าย**

## วางตัวเลขจาก Excel ทีเดียว

เมื่อมีตัวเลขเป็นคอลัมน์อยู่ในตารางคำนวณแล้ว

1. คัดลอกเฉพาะคอลัมน์ตัวเลข
2. คลิกช่องกรอกของเครื่องแรกที่จะวาง แล้ววาง (Ctrl+V)
3. ระบบแสดงกล่องตัวอย่าง "จะวาง N ค่า เริ่มจากแถวที่ N" พร้อมตาราง Serial / เดิม / จะกลายเป็น **ตรวจ Serial ทุกแถวว่าตรงเครื่องที่ตั้งใจ**
4. กด **ยืนยันการวาง** หรือ **ยกเลิก** ตัวเลขที่วางยังไม่ถูกบันทึกจนกว่าจะกด **บันทึก**

ข้อควรระวัง:

- ตัวเลขลงตาม **ลำดับแถวที่เห็นบนจอ** ถ้าตารางถูกกรองหรือเรียงต่างจากตารางคำนวณ ตัวเลขจะลงผิดเครื่อง ดูตาราง Serial ในกล่องตัวอย่างทุกครั้ง
- ค่าที่ไม่ใช่ตัวเลข (เช่นหัวตารางที่ติดมา) ถูกข้าม และระบบบอกว่า "ข้าม N ค่าที่ไม่ใช่ตัวเลข" ช่องเดิมของแถวนั้นไม่ถูกแตะ
- **เซลล์ว่างตรงกลาง** ของคอลัมน์ที่คัดลอกมาจะล้างช่องของเครื่องนั้น (ในกล่องตัวอย่างขึ้น "—") ถ้าช่องนั้นเคยมีตัวเลขบันทึกไว้ ระบบถามก่อนลบตอนกดบันทึก
- เซลล์ว่างที่ **หัวหรือท้าย** ของช่วงที่คัดลอกถูกตัดทิ้ง ตัวเลขจะเลื่อนขึ้นไปลงแถวก่อนหน้า ให้เริ่มคัดลอกจากแถวของเครื่องแรกเสมอ
- ถ้าจำนวนค่ามากกว่าแถวที่เหลือ ระบบบอกว่า "เกินจำนวนแถว N ค่า จะไม่ถูกใช้"
- ค่าเดียว (ไม่มีขึ้นบรรทัดใหม่หรือแท็บ) วางเป็นปกติ ไม่มีกล่องตัวอย่าง

## กรอกทั้งปีของเครื่องเดียว

ใช้เมื่อเก็บมิเตอร์ย้อนหลังของเครื่องเดียวทีละหลายเดือน

1. สลับเป็นโหมด **ภาพรวมทั้งปี**
2. กด **กรอก** ที่แถวของเครื่อง หน้าต่าง "กรอกจำนวนพิมพ์ · (Serial)" เปิดขึ้น
3. กรอกช่องของแต่ละเดือน (หน่วย หน้า) เดือนที่ยังไม่มีข้อมูล **เว้นว่างไว้ได้** ระบบไม่นับเป็นศูนย์
4. วางตัวเลขจาก Excel ที่ช่องแรกได้ ระบบเติมเดือนถัดไปให้ กด Enter เพื่อเลื่อนไปเดือนถัดไป วางผิดกด **เลิกทำการวาง**
5. กด **บันทึกทั้งปี**

## ดูว่ากรอกครบหรือยัง

- ป้ายข้างชื่อหน้า "กรอกครบแล้ว X จาก Y เครื่อง" เป็นสีเขียวเมื่อครบทุกเครื่อง
- กด **รายละเอียดความคืบหน้าปี** เพื่อดู ครบแล้ว / กรอกบางเดือน / ยังไม่กรอก และปุ่ม **ดูเฉพาะที่ยังไม่ครบ** ปุ่มนี้แสดงเฉพาะเครื่องที่ **กรอกบางเดือน** เครื่องที่ยังไม่เคยกรอกเลยไม่อยู่ในรายการ ให้ใช้ตัวกรอง **สถานะการกรอก → ยังไม่กรอก** ดูเครื่องเหล่านั้น
- เดือนที่ยังอ่านมิเตอร์ไม่ได้ (เดือนปัจจุบัน) ไม่นับเป็นงานค้าง
- โหมด **ภาพรวมทั้งปี** มีคอลัมน์ ความคืบหน้า (เช่น 5/7 เดือน) และ ขาวดำล่าสุดที่กรอก

## เมื่อระบบไม่ยอมบันทึกหรือถามก่อน

| ข้อความที่เห็น | แปลว่า | ทำอย่างไร |
|---|---|---|
| **ยังมีข้อมูลที่ยังไม่ได้บันทึก** (ขึ้นเมื่อเปลี่ยนเดือน เปลี่ยนปีงบ สลับโหมด ล้างตัวกรอง หรือออกจากหน้า) | มีตัวเลขที่แก้ไว้แต่ยังไม่ได้กดบันทึก ถ้าไปต่อตัวเลขเหล่านั้นหาย | ปิดกล่องแล้วกด **บันทึก** ก่อน หรือเลือกปุ่มที่มีคำว่า "โดยไม่บันทึก" ถ้าตั้งใจทิ้ง |
| **ยืนยันลบตัวเลขที่บันทึกไว้** "จะลบตัวเลขที่บันทึกไว้ของ N เครื่อง …" | คุณล้างช่องที่เคยมีตัวเลข | ถ้าตั้งใจ กด **ลบและบันทึก** ตัวเลขเดิมหายและรายงานเปลี่ยนตาม ถ้าไม่ตั้งใจ ยกเลิกแล้วพิมพ์ตัวเลขเดิมกลับ |
| **มี N รายการที่เกิน 1,000,000 หน้า กรุณาตรวจก่อนบันทึก** | ตัวเลขใหญ่ผิดปกติ มักเป็นเลขมิเตอร์สะสมหรือพิมพ์เกินหนึ่งหลัก | แก้เป็นจำนวนหน้าของเดือนนั้น แล้วบันทึกใหม่ |
| **มีคนแก้ยอดบางช่องไปแล้วระหว่างที่คุณกรอก — ยังไม่ได้บันทึกอะไร** | อีกคนบันทึกช่องเดียวกันไปก่อน ระบบไม่บันทึกอะไรเลยสักช่อง หน้าโหลดตัวเลขล่าสุดมาแล้ว แต่ **ตัวเลขที่คุณพิมพ์ยังบังตัวเลขของอีกคนอยู่ และระบบไม่ทำเครื่องหมายช่องที่ชน** | **อย่ากดบันทึกซ้ำทันที** เพราะตัวเลขของคุณจะแทนที่ตัวเลขของอีกคนในทุกช่องที่ชน กด **ทิ้งที่แก้ไว้** เพื่อดูตัวเลขล่าสุดในตาราง (ที่พิมพ์ไว้จะหายทั้งหมด) แล้วกรอกใหม่เฉพาะช่องที่ถูกต้อง หรือให้ผู้ดูแลระบบดูที่ **ประวัติการแก้ไข** ว่าช่องไหนถูกแก้โดยใคร |
| **บันทึกไม่ได้ เพราะยอดบางรายการหาราคาไม่ได้ — แก้สัญญาหรือเครื่องก่อน แล้วบันทึกใหม่** พร้อมรายการ Serial · เดือน — เหตุผล | เครื่องนั้นในเดือนนั้นยังคิดเงินไม่ได้ ระบบไม่บันทึกอะไรเลยทั้งชุด | ดูเหตุผลด้านล่าง เจ้าหน้าที่แก้เองไม่ได้ ส่ง Serial เดือน และเหตุผลให้ผู้ดูแลระบบ |
| **บันทึกไม่สำเร็จ กรุณาลองใหม่** | ส่งไม่ถึงหรือระบบขัดข้อง | ตัวเลขที่กรอกไม่หาย กด **ลองบันทึกใหม่** |
| **โหลดจำนวนพิมพ์ของเดือนนี้ไม่สำเร็จ** | ยังไม่รู้ว่าเดือนนี้มีตัวเลขอะไรบ้าง ช่องกรอกถูกปิดไว้เพื่อไม่ให้กรอกทับของเดิมโดยไม่รู้ตัว | กด **ลองใหม่** |
| **เลือกเดือนที่จะกรอกก่อน แล้วตารางกรอกจะขึ้นมา** | ช่อง ดูเดือน เป็น ทั้งปีงบ | เลือกเดือนในช่อง **ดูเดือน** |
| **ไม่มีเครื่องที่ตรงกับเงื่อนไข** | ตัวกรองหรือคำค้นไม่เจอเครื่อง | ล้างตัวกรอง ถ้าเครื่องยังไม่อยู่ในทะเบียน ให้ผู้ดูแลระบบเพิ่มเครื่องที่หน้า **ทะเบียนเครื่องพิมพ์** |

### เหตุผลที่ "หาราคาไม่ได้" และผู้ดูแลระบบแก้อย่างไร

ดูสัญญา หมวดมิเตอร์ และราคาต่อหน้าที่ใช้จริงของเครื่องได้ที่หน้ารายละเอียดเครื่อง (กด Serial ในทะเบียน) การ์ด **ที่ตั้งและสัญญา** ส่วนการแก้ทำที่ **ทะเบียนเครื่องพิมพ์** → ปุ่ม **แก้ไข** ของเครื่องนั้น → ส่วน **สัญญาและราคา**

| เหตุผลที่เห็นต่อ Serial | ผู้ดูแลระบบตรวจและแก้ |
|---|---|
| เครื่องยังไม่ได้ผูกสัญญาในเดือนนี้ | เลือก **สัญญาที่ผูกอยู่** และใส่ **เริ่มคิดเงินตามสัญญานี้ตั้งแต่วันที่** เป็นวันที่ไม่หลังเดือนที่กรอก ถ้าไม่ใส่วันที่ ระบบนับสัญญาจากวันที่บันทึก ซึ่งไม่ครอบเดือนย้อนหลัง ตรวจกับเอกสารก่อนใส่ เพราะมีผลกับข้อมูลย้อนหลัง |
| ประวัติการคิดเงินระบุว่าเดือนนี้เครื่องไม่มีสัญญา | ในเดือนนั้นเครื่องถูกตั้งเป็น "ไม่ผูกกับสัญญา" ตรวจเอกสารว่าเดือนนั้นเครื่องอยู่ใต้สัญญาไหน แล้วตั้ง **สัญญาที่ผูกอยู่** กับ **เริ่มคิดเงินตามสัญญานี้ตั้งแต่วันที่** ให้ครอบเดือนนั้น |
| เดือนนี้อยู่นอกอายุสัญญา (เลขที่สัญญา) | เครื่องผูกสัญญาผิดฉบับ หรือวันเริ่ม/สิ้นสุดของสัญญาไม่ตรงเอกสาร ตรวจที่ **ตั้งค่าระบบ → สัญญา** |
| สัญญา (เลขที่สัญญา) ไม่มีราคาหมวด "(ชื่อหมวด)" | เพิ่มราคาต่อหน้าของหมวดนั้นที่ **ตั้งค่าระบบ → สัญญา** หรือตรวจว่า **หมวดมิเตอร์** ของเครื่องถูกต้อง |

หลังแก้ กลับมากด **ลองบันทึกใหม่** ตัวเลขที่กรอกค้างอยู่
