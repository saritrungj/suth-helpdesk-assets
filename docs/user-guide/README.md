# คู่มือผู้ใช้

คู่มือนี้สำหรับคนที่ใช้หน้าเว็บทำงานจริง — เจ้าหน้าที่ที่บันทึกจำนวนพิมพ์ และผู้ดูแลระบบที่นำเข้าไฟล์และดูแลข้อมูลหลัก ไม่ต้องอ่านโค้ดหรือเอกสารของนักพัฒนา

## เลือกอ่านตามงาน

| งานที่จะทำ | คู่มือ | ใครทำได้ |
|---|---|---|
| บันทึกจำนวนพิมพ์ของเดือนนี้ | [บันทึกจำนวนพิมพ์รายเดือน](record-monthly-pages.md) | เจ้าหน้าที่ ผู้ดูแลระบบ |
| ลงทะเบียนเครื่องและจำนวนพิมพ์จากไฟล์ของผู้ให้เช่า | [นำเข้าไฟล์จากผู้ให้เช่า](import-lessor-file.md) | ผู้ดูแลระบบ |

## บทบาทของคุณ

แถบบนสุดแสดงบทบาทข้างชื่อผู้ใช้ของคุณ

| บทบาทที่แสดง | ทำอะไรได้ |
|---|---|
| ผู้ดูแลระบบ | ทุกอย่างของเจ้าหน้าที่ และจัดการเครื่อง สัญญา ปีงบ ยี่ห้อ อาคาร ฝ่าย แผนก ผู้ใช้ นำเข้าไฟล์ และดูประวัติการแก้ไข |
| เจ้าหน้าที่ | ดูภาพรวม ทะเบียน และรายงาน และบันทึกจำนวนพิมพ์รายเดือน |
| ดูอย่างเดียว | ดูภาพรวม ทะเบียน และรายงาน แก้ไขอะไรไม่ได้ |

เมนู **ตั้งค่าระบบ** และ **นำเข้าไฟล์จากผู้ให้เช่า** เห็นเฉพาะผู้ดูแลระบบ ถ้าเปิดลิงก์ของหน้าเหล่านี้ด้วยบทบาทอื่น ระบบพากลับหน้าภาพรวมพร้อมข้อความ "หน้านี้สำหรับผู้ดูแลระบบ"

## เข้าสู่ระบบ

1. กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** แล้วกด **เข้าสู่ระบบ**
2. ถ้าเห็น "Caps Lock เปิดอยู่" ให้ปิดก่อนกรอกรหัสผ่าน
3. ลืมรหัสผ่านหรือยังไม่มีบัญชี: กด **ลืมรหัสผ่าน?** ใต้ช่องรหัสผ่าน จะมีช่องทางติดต่อแผนกสารสนเทศ
4. เปลี่ยนรหัสผ่านของตัวเอง: เปิดเมนูบัญชีที่แถบบนสุด แล้วเลือก **เปลี่ยนรหัสผ่านของฉัน**

## ปีงบที่กำลังดู

ทุกหน้าแสดงข้อมูลตามปีงบที่เลือกอยู่ที่ปุ่ม **ปีงบ** บนแถบบนสุด กดปุ่มนั้นเพื่อเปลี่ยนปีงบ

- ปีงบแสดงเป็น พ.ศ. และเริ่มวันที่ 1 ตุลาคม สิ้นสุด 30 กันยายน ปีงบ 2569 คือตุลาคม 2568 ถึงกันยายน 2569
- ถ้าปุ่มขึ้น "ยังไม่มี" แปลว่ายังไม่มีปีงบในระบบ ให้ผู้ดูแลระบบสร้างที่ **ตั้งค่าระบบ → ปีงบประมาณ**
- ก่อนบันทึกจำนวนพิมพ์ ตรวจปีงบที่ปุ่มนี้ทุกครั้ง เดือนที่เลือกได้ขึ้นกับปีงบนี้

## คำที่ใช้ในคู่มือ

| คำ | ความหมาย |
|---|---|
| จำนวนพิมพ์ | จำนวนหน้าที่มิเตอร์หนึ่งนับได้ในเดือนหนึ่ง เป็นตัวเลขที่เจ้าหน้าที่กรอกหรือนำเข้า |
| เลขมิเตอร์ | ตัวเลขสะสมบนหน้าปัดของเครื่อง |
| เงินตามใบแจ้งหนี้ | เงินที่ผู้ให้เช่าเรียกเก็บต่องวด |
| ค่าพิมพ์ | ส่วนของเงินตามใบแจ้งหนี้ที่เป็นของมิเตอร์หนึ่ง รวมกันแล้วเป็นค่าพิมพ์ของเครื่อง แผนก หรืออาคาร |
| แทนที่ | ตัวเลขใหม่ในไฟล์จะมาแทนค่าที่บันทึกไว้เดิม |

ตารางเต็มของคำบนหน้าจออยู่ที่ [คำที่ใช้บนหน้าจอ](../reference/ui-words.md) และนิยามตัวเลขอยู่ที่ [คำศัพท์โดเมน](../../CONTEXT.md)

## ติดปัญหา

- ข้อความบนหน้าจอบอกสิ่งที่ต้องทำเป็นภาษาไทยอยู่แล้ว หาข้อความที่เห็นได้ในหัวข้อ "เมื่อระบบไม่ยอมบันทึกหรือถามก่อน" ของคู่มือบันทึกจำนวนพิมพ์ และ "แก้เรื่องที่ระบบหยุดถาม" ของคู่มือนำเข้าไฟล์
- ปัญหาที่คู่มือไม่ครอบคลุม ส่งให้ผู้ดูแลระบบพร้อมชื่อหน้า ข้อความที่เห็น และ Serial ของเครื่อง ห้ามส่งรหัสผ่าน
