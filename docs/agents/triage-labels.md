# Triage Labels

skill พูดถึงบทบาท triage มาตรฐาน 5 แบบ ไฟล์นี้ map บทบาทนั้นไปยังชื่อ label จริงที่ใช้ใน issue tracker ของ repo นี้

| Label ใน mattpocock/skills | Label ใน repo นี้ | ความหมาย |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | ต้องมี maintainer มาประเมิน issue นี้ |
| `needs-info` | `needs-info` | รอผู้แจ้งให้ข้อมูลเพิ่ม |
| `ready-for-agent` | `ready-for-agent` | ระบุ scope ครบแล้ว พร้อมให้ agent ทำแบบ AFK |
| `ready-for-human` | `ready-for-human` | ต้องให้คนลงมือทำเอง |
| `wontfix` | `wontfix` | จะไม่ทำ |

เมื่อ skill พูดถึงบทบาทใด (เช่น "ติด label ready-for-agent") ให้ใช้ชื่อ label ตามตารางนี้

แก้คอลัมน์ขวาได้ตามชื่อ label จริงที่ repo ใช้ ถ้าเปลี่ยนในอนาคต — ตอนตั้งค่านี้ (2026-09-07) สร้าง 4 label ที่ขาดไว้แล้วบน GitHub (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`); `wontfix` มีอยู่ก่อนแล้ว
